# Changelog

All notable changes to Spiggle API Guard are documented here.

## 1.0.0 — 2026-10-27

- Initial release.
- Filament 4 and 5 support.
- Global request tracking with field-level configuration, filters, sampling, redaction and truncation.
- Path/method/IP/user guard rules with block and throttle actions, cached evaluation and hit tracking.
- Feed and detail quick actions for creating block or throttle rules.
- Live request feed, statistics and bottom status dock with background polling and notifications.
- Request detail workspace with request/response/header/context/replay tabs.
- Simulated and live replay with route planning, guardrails and optional database rollback.
- Daily retention pruning and `api-guard:prune` command.
- Access control via gate/email allow list.
