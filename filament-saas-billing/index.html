How it works

Up and running in four steps.

1

Install

composer require spiggle/filament-saas-billing
php artisan vendor:publish --tag=filament-saas-billing-config
php artisan migrate
2

Register

use Spiggle\FilamentSaasBilling\SaasBillingPlugin;

$panel->plugin(SaasBillingPlugin::make());
3

Lemon env

Set store, API key, signing secret, and LS_VARIANT_STARTER / LS_VARIANT_STUDIO.

4

Webhook

Point Lemon at POST /webhooks/lemon-squeezy. Cancelled events drop the workspace to free.
