# Changelog

All notable changes to Spiggle API Inspector are documented here.

## 1.0.0 — 2026-10-27

- Initial release.
- Filament 4 and 5 support.
- Global request capture with field-level configuration, filters, sampling, redaction and truncation.
- Live request feed, statistics and bottom status dock with background polling and notifications.
- Request detail workspace with request/response/header/context/replay tabs.
- Simulated and live replay with route planning, guardrails and optional database rollback.
- Daily retention pruning and `api-inspector:prune` command.
- Access control via gate/email allow list.
