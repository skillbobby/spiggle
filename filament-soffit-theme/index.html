Setup

Install in under two minutes

Require via Composer and register in your panel provider. Soffit takes care of the rest automatically.

1. Install via Composer

composer require spiggle/filament-soffit-theme

2. Register in PanelProvider (Optional if auto_register is true)

use Spiggle\FilamentSoffitTheme\FilamentSoffitThemePlugin; public function panel(Panel $panel): Panel { return $panel // ... ->plugin(FilamentSoffitThemePlugin::make()); }

3. (Optional) Publish configuration

php artisan vendor:publish --tag=filament-soffit-theme-config
Questions & Answers

Frequently asked questions

Which versions of Filament and Laravel are supported?

Soffit supports both Filament 4.x and Filament 5.x on Laravel 11, 12, or 13, and PHP 8.2 through 8.5.

Do I need to rebuild Tailwind CSS or run Vite?

No. Soffit ships as pre-compiled CSS served directly by the package. Once installed and registered, the theme applies instantly with zero build steps.

How does the license work?

You can purchase a Single Site license for $19 (1 production panel) or an Unlimited Projects license for $49 (unlimited client and personal panels). Both include 1 year of updates and security fixes.

Does it work with the Spiggle Theme Switcher?

Yes! When registered alongside Spiggle’s theme switcher plugin, Soffit only activates when selected as the active theme choice in panel settings. Without the switcher, it activates globally on your panel.

Does Soffit interfere with custom Filament form or table components?

No. Soffit styles the outer shell, cards, sidebars, headers, and standard widgets. Your custom forms, fields, schemas, and resource business logic remain completely untouched.
