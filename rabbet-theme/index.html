What the theme carries

The shell is the product. The kit is the same shell with the operations book.

Brand

Mark plus logo text. Replace the text and upload a PNG, WebP, JPG, or SVG.

Language and zoom

English, Español, Français, Português. A− / A / A+ stays in the browser.

List view

Switch a table to an alphabetical list from the header.

Auth

Sign in and registration use the Rabbet card, and link to each other.

Theme options

The mark is in the panel, not only on the page.

Logo text and icon save to the theme options table. A scripted SVG is rejected. A missing file falls back to the bundled mark.

Sign in

Login and registration are part of the theme.

Both pages use the Rabbet card. The language control and zoom sit with the shell, including on a narrow screen.

Audit

A change writes a log and a notification.

Passwords and tokens are left out. Notifications are scoped to the signed-in user. Roles gate audit, notifications, roles, and theme options.

Starter kit

Overview, queues, policies, quotes, claims.

The kit requires the theme and registers it if the panel does not already have it. Seed data fills the reference book. Nothing on the overview is hardcoded.
