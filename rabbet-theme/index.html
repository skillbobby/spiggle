Theme Options

The mark is in the panel, not only in the code.

Logo text and brand marks are stored in a dedicated theme options database table. Administrators can upload brand assets without touching Blade views or CSS files.

Security is built in: uploaded SVG assets with embedded JavaScript or inline script tags are automatically rejected, and missing assets smoothly fallback to the bundled Rabbet mark.

Audit & Security

A change writes a log and notifies the right operator.

Whenever a model or record undergoes changes, an audit record is dispatched alongside an in-app notification. Passwords, secret tokens, and sensitive headers are strictly scrubbed before saving.

Notifications are cleanly scoped to the active signed-in user, and full role-based permissions gate access to audit tables, notifications center, roles management, and theme options.

Quickstart & Setup

Up and running in two minutes

Install via Composer into any Laravel 11, 12, or 13 application running Filament 4 or 5. Zero frontend building or npm dependencies required. 

# 1. Require the Rabbet theme package
composer require spiggle/rabbet-theme

# 2. Run database migrations for theme options & audit trails
php artisan migrate

# 3. Register the theme plugin in your Filament Panel Provider:
->plugin(\Spiggle\FilamentRabbetTheme\RabbetThemePlugin::make())
# 1. Require the starter kit (auto-requires Rabbet theme)
composer require spiggle/rabbet-starter-kit

# 2. Install the operations suite & seed realistic metrics
php artisan rabbet:install --seed

# Done! Visit your Filament panel to explore the live operations book.
// app/Providers/Filament/AdminPanelProvider.php
use Spiggle\FilamentRabbetTheme\RabbetThemePlugin;

public function panel(Panel $panel): Panel
{
    return $panel
        ->default()
        ->id('admin')
        ->plugin(RabbetThemePlugin::make());
}

Questions & Answers

Frequently Asked Questions

Everything you need to know about Rabbet Theme and the Operations Starter Kit.

Does Rabbet require npm, Vite, or Tailwind CLI compilation?
No. Rabbet is pure CSS and Blade template overrides engineered specifically for Filament. It injects directly through Filament's native render hooks. You do not need to modify tailwind.config.js, compile assets, or run npm run build.
Is Rabbet compatible with Filament v4 and Filament v5?
Yes. Rabbet is explicitly authored and continuously tested against both Filament 4 and Filament 5 on Laravel 11, 12, and 13 (PHP 8.2 through 8.5).
What is the difference between the Theme Shell and the Starter Kit?
The Theme Shell (spiggle/rabbet-theme) provides all styling chrome: the forest-green color palette, pill navigation, brand options panel, language switcher, zoom controls, alphabetical list view, audit logging, and auth screens. The Starter Kit (spiggle/rabbet-starter-kit) adds the entire business domain: Underwriting, Policies, Quotes, Claims, Work Queues, and rich database seeders.
Can I upload my own company mark and brand name?
Yes! Rabbet includes a Theme Options settings resource in your admin panel. You can define your panel brand name and upload PNG, WebP, JPG, or SVG logo files. Malicious SVG scripts are filtered out automatically, and missing uploads seamlessly fall back to the bundled Rabbet mark.
How do updates work for the yearly bundle licenses?
Yearly bundle licenses ($29/yr and $79/yr) include 12 months of all new feature updates, new component layouts, and security patches. You can renew each year to continue receiving new releases, or keep running the version you have indefinitely.
