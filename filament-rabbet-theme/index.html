A forest-green shell for the Canopy console.

Pill navigation, serif page titles, and quiet cards. The theme does not install claims, policies, or seed data unless you opt in.

Install

Theme only

Colors, Inter, Source Serif, top navigation, sidebar, login, tables, badges, and modals. No models required.

Optional demo

Switcher ready

Registers as spiggle-rabbet-theme and serves /spiggle/rabbet-theme/theme.css. Paints only while selected.

Install

composer require spiggle/filament-rabbet-theme
php artisan rabbet:install
->plugin(RabbetThemePlugin::make())

Demo: php artisan rabbet:install --demo and ->demo().
