How it works

Install, configure, ship

The plugin registers on the Filament panel. Theme Settings writes Spatie settings. The CSS ships with the package.

1

Register the plugin

Add MaterialThemePlugin::make() on your panel provider. Optional brand title, tagline, density, and demo pages.

2

Open Theme Settings

Upload a logo, pick a primary color, toggle density or dark mode, choose Lucide or Heroicons, and set the promo banner.

3

Keep your resources

Forms and tables stay native Filament. The theme restyles the shell — including login, account, and notifications.

FAQ

Quick answers

What does Material Theme do?

It restyles a Laravel Filament v5 admin to Material Design: type, icons, surfaces, login, top bar, and notifications. You change brand, colors, density, and the promo banner from Theme Settings. It does not replace your resources, forms, or tables.

Do I need a Vite / Tailwind rebuild?

No. Theme CSS ships with the package. Register the plugin and the panel picks it up.

Which versions are supported?

Laravel 13 and Filament 5 are the primary target. PHP 8.3+.

Is this the same as Spiggle Theme?

No. Spiggle Theme is a separate product: four sidebar layouts and six palettes. Material Theme is a Material Design shell with Theme Settings, notifications, search, and a promo banner.

How do I get the package?

The Composer package is licensed separately from this public page. Email skillbobby@outlook.com for access.

Does it work in a subdirectory install?

Yes. Asset URLs use Laravel’s asset() helper, so a panel at /spiggle/admin still loads logos and theme files.
