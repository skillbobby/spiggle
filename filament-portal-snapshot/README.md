# Spiggle Filament Portal Snapshot

Public product page for the private package
[`skillbobby/Spiggle-Filament-Portal-Snapshot`](https://github.com/skillbobby/Spiggle-Filament-Portal-Snapshot).

Live page: [skillbobby.github.io/spiggle/filament-portal-snapshot](https://skillbobby.github.io/spiggle/filament-portal-snapshot/)

Filament 4 + 5 plugin on top of `spatie/laravel-db-snapshots`:

- create / restore / export dumps from the panel
- golden snapshot for demo baselines
- schedules including a midnight demo reset
- remote copy to any Laravel disk (S3, Drive, …)
- Filament bell + queued email (mail fails silently)

Source stays in the private repo. This folder is the public feature page only.
