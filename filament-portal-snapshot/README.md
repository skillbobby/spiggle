# Spiggle Filament Portal Snapshot

Public product page for [`skillbobby/Spiggle-Filament-Portal-Snapshot`](https://github.com/skillbobby/Spiggle-Filament-Portal-Snapshot).

Live page: [skillbobby.github.io/spiggle/filament-portal-snapshot/](https://skillbobby.github.io/spiggle/filament-portal-snapshot/)

Filament 4 + 5 plugin for database snapshots & automated demo resets:

- Create, restore, and export dumps from the panel
- Golden snapshot for known-good demo baselines
- Automated schedules including midnight demo reset
- Remote copy to any Laravel Flysystem disk (S3, GCS, SFTP, etc.)
- Filament bell notifications + queued operational emails
