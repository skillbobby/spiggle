Everything you need

A Filament plugin, not a demo app. Limits resolve from SaaS Billing when installed.

Four views

Board, List, Table, and Vision Board on one Livewire page.

Vision Board

Notes, images, quotes, goals, and links as stickies. Pin tasks onto the canvas.

Calendar + reporting

Due-date calendar and counts, overdue work, and plan usage.

Spatie stack

media-library, tags, translatable names. Permission-ready host.

Usage gates

UsageGate blocks new boards/tasks at plan cap. Soft-depends on billing.

How it works

Up and running in four steps.

1

Install

composer require spiggle/filament-visual-board
php artisan vendor:publish --tag=filament-visual-board-migrations
php artisan migrate
2

Register

use Spiggle\FilamentVisualBoard\VisualBoardPlugin;

$panel->plugin(VisualBoardPlugin::make());
3

Seed in the host

Create workspaces from your app seeder. The plugin will not invent demo rows.

4

Optional billing

Install filament-saas-billing so UsageGate reads plan limits.
