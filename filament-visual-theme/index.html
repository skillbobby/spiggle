Everything you need

Theme tokens live in config. No product copy is baked into the plugin.

Six palettes

Emerald Forest, Ocean Teal, Royal Violet, Sunset Amber, Coral Rose, Graphite Slate.

Appearance page

Filament Settings page. ThemeManager writes the chosen key.

Header switcher

Optional USER_MENU_BEFORE hook so operators can change palette in place.

CSS variables

Injects --spiggle-primary, --spiggle-accent, --spiggle-ink on HEAD_END.

Persistence

settings (Spatie), user_attribute, or session — set in config.

Inter + colors

Panel font is Inter. Primary maps to Color::hex of the current palette.

How it works

Up and running in three steps.

1

Install

composer require spiggle/filament-visual-theme
php artisan vendor:publish --tag=filament-visual-theme-config
2

Register

use Spiggle\FilamentVisualTheme\VisualThemePlugin;

$panel->plugin(VisualThemePlugin::make());
3

Persistence

Default is Spatie Settings. Switch to a user column or session in config.
